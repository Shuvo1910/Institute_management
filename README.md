# Institute_management
University/Institute Management System built with Django web application, designed to digitize and automate core academic and administrative workflows

Main Function Model (Basic Level)

1. User Authentication & Role Management
	* Login, logout, and password management using Django’s built-in authentication system.
	* Role-based permissions to restrict what Admins, Staff, and Students can see and edit.
3. Student & Staff Information System
	* Student Module: Add, edit, view, and delete student records (Roll number, Name, Department, Semester, Contact info).
	* Staff/Faculty Module: Add, edit, and assign teachers to specific departments and courses.
4. Department, Course & Subject Management
	* Create and manage academic departments (e.g., Computer Science, Engineering, Business).
	* Map subjects and courses to respective semesters and departments.
5. Attendance Management System
	* Staff can mark day-to-day or subject-wise attendance for students.
	* Students can log in to view their individual attendance percentage and records.
6. Grade
	* Staff can input marks or grades for subjects.
	* Students can view their academic performance and marks per subject.
7. Notices
	* An admin or staff bulletin board to post campus or class-wide announcements visible on user dashboards.
